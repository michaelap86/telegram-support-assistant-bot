# Payments and account

## Payment methods
We accept Visa, Mastercard, American Express, PayPal, Apple Pay, Google Pay and iDEAL. Cards are charged when the order is packed, not when it is placed.

## Discount codes
Enter the code at checkout. Only one code can be used per order and codes cannot be applied after the order is placed. The code WELCOME10 gives 10 percent off the first order.

## Invoices
An invoice is attached to the shipping confirmation email. If you need a copy with a company name or VAT number, write to billing@novagear.example with your order number.

## Cancelling an order
An order can be cancelled for free while its status is "processing". Once the parcel has shipped it can no longer be cancelled, but you can refuse the delivery or return it within 30 days.

## Contacting a human
Our team works Monday to Friday from 09:00 to 17:00 CET. Outside these hours the assistant can still answer most questions and will pass anything else to the team for the next morning.
